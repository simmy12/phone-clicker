# טריוויה בקליקרים טלפוניים

- `/admin.html`: יצירת משחק ללקוח (מקבלים קישור ניסיון + קישור למשחק החד־פעמי)
- `public/themes/hanukkah/`: ערכת חנוכה (רקעים, קישוטים, שאלות, תמונות זיכרון)
- `public/themes/base/`: גביעים, סמלים, פודיום ומטבע, משותפים לכל הנושאים
- `public/lang/he.json`: כל הטקסטים במסך (לתרגום: יוצרים en.json)
- `public/sounds/`: מוזיקה וצלילים (אם קובץ חסר, המשחק משתמש בצליל חלופי)

הגדרות ב-Render: HOST_KEY, TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, ובהמשך DATABASE_URL

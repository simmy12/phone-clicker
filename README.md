# חידון טלפוני – גרסת בדיקה

משתתפים מתקשרים למספר אמריקאי ועונים בעזרת המקשים. זה עובד מכל טלפון, גם מטלפון כשר.
המנחה מפעיל את החידון ממסך בדפדפן.

## מה צריך (פעם אחת)

1. **חשבון Twilio** (ספק הטלפוניה): https://www.twilio.com/try-twilio
   - בחשבון ניסיון מקבלים קרדיט חינם. אפשר לקנות בו מספר אמריקאי ולבדוק.
   - בחשבון ניסיון רק מספרים שאישרת מראש יכולים להתקשר, ובתחילת כל שיחה מושמעת הודעת ניסיון.
     כדי לפתוח את המספר לכולם צריך להטעין לפחות 20$.
2. **חשבון GitHub**: https://github.com (כדי לשמור את הקוד).
3. **חשבון Render**: https://render.com (השרת שמריץ את המערכת).

## שלב 1 – להעלות את הקוד ל-GitHub
יוצרים ריפו חדש ומעלים אליו את כל הקבצים מהתיקייה (בלי התיקייה node_modules).

## שלב 2 – להריץ את השרת ב-Render
1. New → Web Service → בוחרים את הריפו.
2. Build Command: `npm install`  ·  Start Command: `npm start`
3. ב-Environment מוסיפים:
   - `HOST_KEY`: סיסמה למסך המנחה (בחרי בעצמך)
   - `TWILIO_ACCOUNT_SID`: מהדף הראשי של Twilio
   - `TWILIO_AUTH_TOKEN`: מהדף הראשי של Twilio
4. אחרי שהשרת עולה מקבלים כתובת, למשל `https://phone-clicker.onrender.com`

> בתוכנית החינמית של Render השרת "נרדם" אחרי 15 דקות בלי שימוש.
> לפני בדיקה פותחים את מסך המנחה ומחכים שייטען, וזה מעיר אותו.
> לאירוע אמיתי עדיף התוכנית בתשלום (בערך 7$ לחודש).

## שלב 3 – לחבר את המספר
ב-Twilio: Phone Numbers → Manage → Active numbers → לוחצים על המספר:
- **A call comes in** → Webhook → `https://הכתובת-שלך/voice` → HTTP POST
- **Call status changes** → `https://הכתובת-שלך/status` → HTTP POST
- שומרים.

## שלב 4 – בדיקה
1. פותחים `https://הכתובת-שלך/host` ומקלידים את הסיסמה.
2. מתקשרים למספר. המשתתף אמור להופיע במסך המנחה.
3. לוחצים "פתח שאלה הבאה". השאלה מוקראת בטלפון, ועונים במקש.
4. "סגור שאלה" → בטלפון שומעים אם התשובה נכונה, ובמסך רואים כמה ענו כל תשובה.
5. "סיים חידון" → כל משתתף שומע את התוצאה שלו והשיחה מסתיימת.

**מקשים בטלפון:** 1–4 בחירת תשובה · כוכבית (*) השמעה חוזרת של השאלה.

**בדיקת עומס בלי טלפונים:** הכפתור "הוסף 20 משתתפים מדומים" מוסיף משתתפים שעונים אקראית.

**שאלות:** בקובץ `questions.json`. השדה `correct` הוא מספר המקש של התשובה הנכונה.
